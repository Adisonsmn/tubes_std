# 📘 Tugas Besar Struktur Data – C++

Project ini dibuat untuk memenuhi **Tugas Besar Mata Kuliah Struktur Data**.  
Program ditulis menggunakan **bahasa C++** dan dapat dijalankan di Windows menggunakan **MinGW (GCC)**.  
Dokumentasi ini berisi cara instalasi, cara compile dan cara running nya.

---

## 🚀 Fitur Utama
- Implementasi struktur data sesuai ketentuan tugas.
- Program berjalan di terminal (Command Line Interface).
- Validasi input untuk mencegah kesalahan pengguna.
- Kode disusun modular agar mudah dipahami dan dikembangkan.

---

## 🛠 Instalasi Compiler C++ (MinGW)

### 1. Download MinGW
Unduh MinGW melalui link resmi:  
https://sourceforge.net/projects/mingw/

### 2. Install paket berikut:
- `mingw32-gcc-g++` (Compiler C++)


### 3. Verifikasi instalasi
Jalankan di terminal:

```bash
g++ --version
```
### 4. Clone repository
```bash
git clone https://github.com/Adisonsmn/tubes_std
cd tubes_std
mkdir exe
```
### 5. Running 
```bash
g++ ./main.cpp ./mll.cpp -o/exe/main;./exe/main
```
